Setup

  1. Install HWiNFO64 8.41 or newer. It reads the WireView Pro II directly, so close the Thermal Grizzly WireView app (the two cannot share the USB port).
  2. In HWiNFO: Sensors-only mode, and Settings → Main Settings → Shared Memory Support on. The free version stops the feed after 12 hours per session; HWiNFO Pro removes that cap.
  3. Run the bridge from this repository: python bridge/wireview_bridge.py (Python 3.10+, no packages). It serves JSON at http://localhost:8765/api/wireview and also serves these widgets locally. bridge/install-startup.ps1 makes it start at login.
  4. In iCUE, open the Xeneon Edge, add an iFrame widget, and paste one of the widget URLs above. Add ?wire_limit=10.5&total_limit=55&cable_w=600 to match the limits set in the WireView device.

URL options

OptionDefaultMeaning
hosthttp://localhost:8765Bridge origin
wire_limit10.5Amps per wire shown as 100 % (per-wire widget)
total_limit55Amps total shown as 100 % (total current widget)
cable_w600Cable rating in W (total power widget)
decimals2Decimals on headline numbers
interval1000Poll interval in ms
accent, bg, fgorange / black / whiteHex colours without #
label=0Hide the caption line

Warning colour starts at 80 % of a limit, critical at 100 %; the device's own fault flags (over-current, over-power, over-temperature, imbalance) always show as critical with their name.
